# Pricing research, October 2026

Decision date: 2026-10-28. Decided by the owner, who made the findings below final. This note feeds concept note section 8.4 and the catalogue data (SUB-01, ONB-03).

## Method

1. Searched the web on 2026-10-28 for current prices of the tools an SME in Kenya or the DRC would compare us with, in each product's own currency, monthly and yearly where shown.
2. Kept the figure closest to a published list price. Vendor blogs and directory listings (Capterra, Software Advice, aggregators) disagree with each other; where they do, the table shows the range and marks confidence low.
3. Converted at about KES 129 to USD 1 for comparison only. The catalogue stores KES (Kenya) and USD (DRC) separately, so no conversion enters the data. CDF is not a billing currency in the catalogue (the DRC bills USD), so no CDF price is set.
4. Priced each module at or slightly below the closest comparable local tool, per the unit the catalogue already uses (outlet, device, company, employee). Where evidence is thin (fuel station, DRC), the price rests on the nearest dependable comparable and is flagged.
5. Kept the platform's model, with no new billing mechanics. The yearly price is the concept note's 2 months free (10 months charged for 12, the existing annual discount row). Bundles stay 15 to 25% under the à la carte total.

## Where the prices live and how staging picks them up

- Tables `catalogue_modules`, `catalogue_bundles` and `catalogue_prices`. Prices are versioned and never edited, so a change is a new row with a later `effective_from`.
- `api/database/migrations/2027_01_13_000100_set_market_catalogue_prices.php` holds the full table above. It writes a new row, effective from the day it runs, only for an item whose current price differs, so running it again writes nothing. Staging and production pick the prices up with `composer migrate` (as `app_owner`).
- The six newer modules' own catalogue migrations now carry the final prices, so a fresh database starts with them and the new migration only changes the older rows.
