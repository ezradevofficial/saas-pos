Set the company-wide rules for quotes, default lead handling and lost deals.

1. Open "Sales settings". Choose the company if you have several, then the "General" tab.
2. Under "Quote approval above", enter the amount above which a quote needs approval. Leave it empty so no quote needs approval.
3. Set "Quote validity in days": how long a new quote stays valid unless you set a date.
4. Choose the "Default team for new leads". Leads that match no assignment rule go to this team in turn, or choose "No team: leave them unassigned".
5. Switch on "Require a reason when an opportunity is lost" if you want lost reasons to show where deals slip away.
6. Tap "Save settings".

People who can only read the settings see "You can see these settings. Ask an admin to change them."
