Tax categories group items taxed the same way. Price lists hold the prices you sell at, in one currency each.

To add a tax category:

1. Open Finance, then "Taxes".
2. Open the "Categories" tab and tap "Add category".
3. Type the "Name" and tap to save. Then choose the default tax code for the company.

To add a price list:

1. Open the "Price lists" tab and tap "Add price list".
2. Type the "Name" and choose the "Currency".
3. Switch on "Prices include tax" if tax is part of the price shown to customers.
4. Switch on "Make this the default list for its currency" if it should be the default list for its currency. The current default in that currency stops being the default.
5. Save the list, then open it to enter the "Prices".
