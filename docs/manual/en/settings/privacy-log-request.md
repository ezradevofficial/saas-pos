A person can ask to see, correct or delete the personal data you hold about them. Log each request here so it is answered on time.

1. Open Settings, then "Privacy".
2. On the "Data requests" tab, tap "Log a request".
3. Under "The request is about a", choose "Customer", "Employee" or "User", then choose the person under "Person".
4. Choose the "Request": "Access", "Correction" or "Deletion".
5. For a correction, fill in only the details that change under "Corrected details".
6. Write a "Note": how the request arrived and how you checked the person's identity.
7. Tap "Log request".

Each request shows when it was received and when it is due. Overdue requests are marked. Use the filter "Show" to see open, completed or rejected ones.
