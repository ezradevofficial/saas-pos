The valuation shows what the stock on hand is worth, in each company’s base currency, using the company’s costing method.

1. Open "Valuation" under "Inventory".
2. Read the tiles at the top. "Total value in" followed by a currency code gives the total for that currency.
3. In the list, read "Quantity", "Unit", "Unit cost" and "Value" for each item. The biggest values come first.
4. Search with "Search by item code or name". Narrow the list with "Company" and "Category".
5. Tap an item to open its stock, with its places, batches and movements.

If you see "No stock to value yet.", no stock has been received or counted. The costing method is chosen in "Inventory settings"; see "Choose how stock is costed".
