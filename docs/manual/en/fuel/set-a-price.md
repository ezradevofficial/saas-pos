The price per litre is typed in from the regulator's notice. {{app_name}} has no prices built in.

1. Open "Fuel prices". "Prices in force" lists what applies now.
2. Tap "Add price".
3. Choose the "Station" and the "Product". Type the "Price per litre".
4. Leave "Starts at" empty to start now, or set a later time to schedule the price. It cannot start in the past.
5. Type the "Reference", for example the notice number. Tap "Save price".

A saved price cannot be changed. To withdraw one that has not started, tap "Withdraw" on it.
