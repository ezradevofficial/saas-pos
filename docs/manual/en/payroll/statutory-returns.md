Returns are built from the posted runs of a month or a year, as CSV files. Their layouts and rates come from the country pack. A return marked "Layout to be confirmed" is a draft file: check it before you file.

1. Open "Statutory returns" under "Payroll".
2. Under "Generate a return", choose the "Return".
3. Choose the "Month", or type the "Year" for a yearly return.
4. Tap "Generate return".
5. In the list, tap "Download CSV" on the new return.

Only the record of the return is kept. The file is rebuilt each time you download it.
