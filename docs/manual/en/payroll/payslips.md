One payslip is issued per employee when a run is posted. Every view and download is recorded.

1. Open "Payslips" under "Payroll".
2. Type a name or number in "Search payslips". To read the payslips of one run, open the run and tap "View payslips"; "Show all payslips" clears that filter.
3. Tap a payslip to read it.
4. Tap "Download PDF" to save it.

An employee reads their own payslips under "My payslips". The amounts on a payslip come from the posted run and the country pack’s values in force for the period.
