The server keeps a sale it finds something to check in: an expired batch, a missing prescription or an unproven approval. A pharmacist reviews each one.

1. Open "Dispenses to review". Search by receipt, patient or prescriber.
2. Read the "Flags" of each sale.
3. Tap "Review" on the row of a sale marked "To review".
4. Under "What you checked", write what you verified. The note is kept with the sale.
5. Tap "Close review". The sale then shows "Reviewed".
