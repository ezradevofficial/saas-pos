Labels carry the asset tag with a barcode, printed through the label template.

1. Open "Labels" under "Fixed assets".
2. Under "Choose assets", search with "Search assets" and tick each asset.
3. Tap "Print" followed by the number of labels, for example "Print 3 labels". The labels open ready to print.
4. Tap "Download PDF" instead to keep a file.

You can also print one label from the asset’s own page with "Print label".
