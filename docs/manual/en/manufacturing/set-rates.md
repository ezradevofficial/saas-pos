The company’s rates are used when an order is released, and in recipe costing.

1. Open "Manufacturing settings" under "Manufacturing". If you have several companies, choose the "Company".
2. Type "Labour per hour" and "Overhead per labour hour", in the company’s currency.
3. Turn on "Releasing an order needs approval" if a branch manager must approve each release before materials can be issued.
4. Tap "Save settings".

Without the right to see costs, the rates show "Hidden". Without the right to edit, the page says "You can see these settings but not change them."
