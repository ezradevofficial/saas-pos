If your role requires it, {{app_name}} asks you to set up two-step sign-in before you continue.

## Set it up

1. Sign in. The page "Set up two-step sign-in" opens.
2. Tap "Use an authenticator app".
3. Scan the QR code with the authenticator app on your phone. If you cannot scan, type the key shown under "Or enter this key by hand".
4. Type the 6-digit code the app shows.
5. Tap "Turn on two-step sign-in".

Codes by text message are not available yet.

## Sign in afterwards

1. Type your email address and password, then tap "Sign in".
2. On "Two-step sign-in", type the code from your authenticator app.
3. Tap "Verify and sign in".

If the page says your sign-in timed out, sign in again to get a new code.
