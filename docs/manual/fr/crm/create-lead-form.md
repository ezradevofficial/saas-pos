Un formulaire sur votre site crée un prospect à chaque envoi.

1. Ouvrez « Paramètres des ventes » et l'onglet « Formulaires ».
2. Touchez « Nouveau formulaire de prospects ». Saisissez le nom et choisissez la « Succursale » à laquelle appartiennent les prospects. Choisissez éventuellement une « Origine » et une « Équipe ».
3. Sous « Champs affichés », choisissez ce que les visiteurs remplissent, et sous « Champs obligatoires » ce qu'ils doivent remplir. Seuls les champs affichés peuvent être obligatoires.
4. Enregistrez. Une fenêtre « Copiez ce lien maintenant » apparaît. Touchez « Copier le lien », ou « Copier le code » pour copier le code à coller sur votre site, puis « Terminé ». Le lien n'est affiché qu'une fois.

La liste montre « Prospects reçus » et « Dernier prospect » pour chaque formulaire. « Nouveau lien » crée un lien et désactive l'ancien. « Archiver <nom> » désactive un formulaire.
