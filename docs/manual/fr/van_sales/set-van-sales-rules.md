---
Choisissez si les vendeurs enregistrent leur position à chaque arrêt, et comment le crédit décidé hors ligne est signalé.

1. Ouvrez « Paramètres » sous la vente en tournée. Choisissez la société si on vous le demande.
2. Sous « Position à l'arrivée », choisissez « Désactivée » ou « Facultative » pour « Position à l'arrivée ». Saisissez « Conserver les positions (jours) », un nombre entier de 1 à 90. Seuls les utilisateurs autorisés à suivre les visites peuvent lire les positions, qui n'apparaissent jamais dans le journal d'audit.
3. Sous « Ventes à crédit », activez « Signaler pour vérification les crédits décidés hors ligne » si vous voulez ces ventes dans « Vérification des crédits ».
4. Touchez « Enregistrer les paramètres ».
