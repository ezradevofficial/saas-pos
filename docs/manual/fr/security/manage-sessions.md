« Sessions » liste les appareils sur lesquels vous êtes connecté. Terminez toute session que vous ne reconnaissez pas.

1. Ouvrez Paramètres, puis « Sessions ».
2. Lisez chaque ligne : « Appareil », « Adresse IP » et « Dernière activité ». Votre session actuelle est marquée « Cet appareil ».
3. Touchez « Se déconnecter » à côté d'une session que vous ne reconnaissez pas.
4. Confirmez. Les autres sessions restent connectées.

Si vous pensez que quelqu'un d'autre a votre mot de passe, terminez les sessions, puis changez votre mot de passe avec « Mot de passe oublié ? » sur la page de connexion. La réinitialisation vous déconnecte partout.

Pour terminer toutes les sessions d'une autre personne, ouvrez-la sous Paramètres, Utilisateurs et touchez « Déconnecter partout ».
