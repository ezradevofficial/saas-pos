Si votre rôle l'exige, {{app_name}} vous demande de configurer la connexion en deux étapes avant de continuer.

## La configurer

1. Connectez-vous. La page « Configurer la connexion en deux étapes » s'ouvre.
2. Touchez « Utiliser une application d'authentification ».
3. Scannez le QR code avec l'application d'authentification de votre téléphone. Si vous ne pouvez pas scanner, saisissez la clé affichée sous « Ou saisissez cette clé à la main ».
4. Saisissez le code à 6 chiffres affiché par l'application.
5. Touchez « Activer la connexion en deux étapes ».

Les codes par SMS ne sont pas encore disponibles.

## Se connecter ensuite

1. Saisissez votre adresse e-mail et votre mot de passe, puis touchez « Se connecter ».
2. Sur « Connexion en deux étapes », saisissez le code de votre application d'authentification.
3. Touchez « Vérifier et se connecter ».

Si la page indique que votre connexion a expiré, reconnectez-vous pour recevoir un nouveau code.
