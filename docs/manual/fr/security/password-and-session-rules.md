---
Ces règles s'appliquent à toutes les personnes de votre organisation.

1. Ouvrez Paramètres, puis « Sécurité ».
2. Réglez la « Longueur minimale du mot de passe » : de 8 à 64 caractères. Elle s'applique la prochaine fois qu'un mot de passe est défini.
3. Réglez le « Délai d'expiration de session » : de 15 à 480 minutes d'inactivité avant la déconnexion.
4. Choisissez la « Langue par défaut ». Elle sert pour les e-mails et pour les personnes qui n'ont pas choisi de langue.
5. Touchez « Enregistrer les modifications ». La page confirme « Paramètres enregistrés. »
