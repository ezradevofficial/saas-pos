Le plan comptable liste tous les comptes sur lesquels la société comptabilise.

1. Ouvrez « Plan comptable » sous « Comptabilité ». L’onglet « Comptes » les liste.
2. Si la société n’a pas encore de plan, choisissez le « Plan type » (le pays de la société par défaut) et touchez « Créer le plan comptable ». Vous pourrez ajouter des comptes ensuite.
3. Pour ajouter un compte, touchez « Ajouter un compte ».
4. Saisissez le « Code » et le « Nom ». Choisissez le « Type » et le « Sous-type ».
5. Choisissez le « Compte de regroupement » et la « Classe de flux de trésorerie » s’ils s’appliquent. Laissez « Imputable » activé pour les comptes qui reçoivent des écritures.
6. Touchez « Enregistrer le compte ».

Pour modifier un compte, touchez « Modifier » sur sa ligne. Pour ne plus l’utiliser, touchez « Archiver » ; « Restaurer » le ramène. L’onglet « Paramètres » indique les comptes utilisés pour les créances, les dettes, les taxes, les écarts de change et la clôture d’exercice.
