Renommez, réordonnez, regroupez et masquez des éléments du menu pour l'organisation ou un rôle, et choisissez la page de départ du rôle. Masquer un élément ne fait que ranger le menu. Les permissions décident toujours de ce qu'une personne peut ouvrir.

1. Ouvrez Paramètres, puis « Menus ».
2. Choisissez à qui s'adresse le menu sous « S’applique à ».
3. Sous « Menu », faites glisser les groupes et les éléments par leurs poignées pour les réordonner, ou placez le focus sur une poignée, appuyez sur Espace et utilisez les flèches.
4. Saisissez un nouveau nom dans le champ de nom d'un élément ou d'un groupe. Utilisez « Ajouter un groupe » pour ajouter un groupe et le champ de groupe d'un élément pour l'y placer.
5. Utilisez la commande d'affichage d'un élément pour le retirer du menu.
6. Sous « Page d’accueil », choisissez la page de départ.
7. Vérifiez l'« Aperçu », touchez « Enregistrer le brouillon », puis touchez le bouton « Publier » avec le numéro de la prochaine version.
