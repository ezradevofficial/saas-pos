Choisissez comment chaque type de notification vous parvient.

1. Ouvrez Paramètres, puis « Notifications ».
2. Pour chaque notification, cochez les canaux souhaités : dans l'application, courriel, notification push, SMS ou WhatsApp. Un canal marqué « Exigé par votre organisation » ne peut pas être désactivé.
3. Sous « Envoi des e-mails », choisissez « Immédiatement », « Résumé quotidien » ou « Résumé hebdomadaire ». Une notification que votre organisation exige par courriel arrive immédiatement.
4. Touchez « Enregistrer les modifications ». La page confirme « Paramètres de notification enregistrés. »

Touchez « Annuler les modifications » pour annuler les changements non enregistrés.
