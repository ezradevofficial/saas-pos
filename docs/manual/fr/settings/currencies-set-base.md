Avertissement : les comptes sont tenus dans la devise de base, qui se verrouille après la première écriture. Choisissez-la avec soin avant que la société n'enregistre quoi que ce soit.

1. Ouvrez Finances, puis « Devises ».
2. Choisissez la société dans le sélecteur de société, ou dans la liste de la page.
3. Dans la carte « Devises de base et de reporting », choisissez la « Devise de base ».
4. Sous « Devises de reporting », choisissez jusqu'au nombre autorisé d'autres devises que les rapports peuvent aussi afficher. Choisissez « Aucune » pour en laisser une vide.
5. Touchez « Enregistrer les devises ». La page confirme « Devises enregistrées. »

Une fois des montants comptabilisés, la carte affiche « Devise de base verrouillée » et la devise de base ne peut plus changer.
