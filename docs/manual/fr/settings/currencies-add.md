Les devises activées peuvent être utilisées par toutes les sociétés pour les prix, les paiements et les taux.

1. Ouvrez Finances, puis « Devises ».
2. Touchez « Ajouter une devise ».
3. Sous « Choisissez une devise », choisissez la devise, puis touchez « Ajouter la devise ».
4. Pour modifier une devise, touchez « Modifier » sur sa ligne. Réglez les « Décimales » et l'« Arrondi espèces » : les totaux en espèces sont arrondis à un multiple de ce montant, par exemple CDF 50 ou KES 1.00.
5. Utilisez l'interrupteur de la ligne pour activer ou désactiver une devise. « Désactivée » l'empêche d'être utilisée pour de nouveaux prix et paiements.

Les décimales se verrouillent dès que des montants sont enregistrés dans la devise. Si vous changez les décimales, l'arrondi est effacé et vous le saisissez de nouveau.
