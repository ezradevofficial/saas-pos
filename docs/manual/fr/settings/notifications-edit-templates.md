Modifiez les textes que votre organisation envoie, par notification et par canal. Le texte est rédigé une seule fois, dans la langue de votre organisation, et chacun le reçoit tel quel.

1. Ouvrez Paramètres, puis « Modèles de notification ».
2. Sous « Types de notification », choisissez la notification.
3. Choisissez le « Canal ».
4. Rédigez l'« Objet » (courriel) et le « Message ». Touchez un espace réservé sous « Variables » pour l'insérer à l'endroit du curseur. Utilisez uniquement les espaces réservés de cette notification.
5. Consultez l'« Aperçu avec des valeurs d’exemple ».
6. Touchez « Enregistrer le modèle ».

Pour revenir au texte intégré, touchez « Utiliser le texte par défaut » et confirmez avec « Utiliser le texte par défaut ». Chacun reçoit alors le texte par défaut dans sa propre langue.

Avec le droit de modifier les paramètres de notification, vous pouvez aussi choisir les « Canaux obligatoires » : des canaux que les utilisateurs ne peuvent pas désactiver pour cette notification.
