Les modes de paiement sont les façons dont les clients paient en caisse, dans l'ordre où la caisse les affiche.

1. Ouvrez Finances, puis « Moyens de paiement ».
2. Choisissez la société dans le sélecteur de société.
3. Utilisez l'interrupteur d'un mode pour l'activer ou le désactiver en caisse. Un mode marqué « À configurer » ne peut pas être activé tant que ses réglages ne sont pas complets (voir « Saisir les clés d'un fournisseur de paiement »). Un mode ne peut pas être activé si sa devise est désactivée ; activez d'abord la devise sous Finance, puis « Devises ».
4. Utilisez les boutons monter et descendre d'une ligne pour changer l'ordre d'affichage en caisse. La page annonce la nouvelle position.
