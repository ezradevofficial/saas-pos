Les codes de taxe portent des taux datés. Un nouveau taux s'applique à partir de la date choisie, et le taux précédent se termine la veille. Ne devinez jamais un taux : prenez-le à la source officielle de l'autorité fiscale.

1. Ouvrez Finances, puis « Taxes ».
2. Choisissez la société dans le sélecteur de société. L'onglet « Codes de taxe » liste ses codes et le taux en vigueur aujourd'hui.
3. Si la société n'a pas encore de codes, touchez « Appliquer le pack pays », puis « Ajouter les codes manquants ». Cela ajoute les codes du pack pays que la société n'a pas encore. Les codes et taux que vous avez déjà ne sont jamais modifiés.
4. Un code marqué « Taux à saisir » n'a pas de taux confirmé. Touchez « Ajouter un taux » sur ce code.
5. Saisissez le « Taux » en pourcentage, et la date sous « En vigueur à partir du ».
6. Touchez « Ajouter le taux ».

Un code à taux zéro a toujours un taux de 0 %. Touchez « Taux » sur un code pour voir son historique.
