Créez les formulaires dont votre organisation a besoin, comme une demande de petite caisse : leurs champs, lignes, pièces jointes, numérotation et approbation.

1. Ouvrez Paramètres, puis « Formulaires ».
2. Touchez « Nouveau formulaire ».
3. Saisissez le « Nom » tel que les gens le verront, par exemple Demande de petite caisse. Vérifiez la « Clé » ; elle ne pourra plus changer.
4. Ajoutez une « Présentation » si c'est utile.
5. Activez « Envoyer chaque formulaire pour approbation » si chaque formulaire doit être approuvé, « Ajouter un tableau de lignes » s'il contient un tableau de lignes, et « Autoriser les fichiers joints » si les gens peuvent joindre des fichiers.
6. Sous « Rôles qui utilisent ce formulaire », choisissez les rôles qui utilisent le formulaire. Laissez vide pour tous ceux qui peuvent utiliser des formulaires. Les propriétaires le peuvent toujours.
7. Touchez « Créer le formulaire ».
8. Ouvrez le formulaire dans la liste pour régler le reste : « Champs » et « Champs de ligne » (ce sont des champs personnalisés), « Mise en page », « Numérotation » et « Circuit d’approbation ».

Utilisez « Modifier » pour modifier un formulaire plus tard et « Archiver » pour le retirer.
