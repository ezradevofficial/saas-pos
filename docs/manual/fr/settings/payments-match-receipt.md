Les demandes de paiement mobile des caisses apparaissent sous « Demandes de paiement ». Les sommes reçues qui ne correspondent à aucune demande apparaissent sous « Reçus non rapprochés », par exemple quand un client a payé avec un mauvais compte.

1. Ouvrez Finances, puis « Paiements reçus ».
2. Choisissez la société dans le sélecteur de société.
3. Pour suivre une demande, restez sur « Demandes de paiement ». Cherchez par référence ou par code M-Pesa, et filtrez par statut. Une demande affiche « Payé », « Échoué », « Délai dépassé » ou un autre statut.
4. Pour régler un reçu, ouvrez « Reçus non rapprochés ». Le filtre « Non rapprochés » montre ce qui reste.
5. Touchez « Rapprocher d’un paiement » sur le reçu.
6. Sous « Demande de paiement », choisissez la demande de paiement qu'il règle, puis touchez « Rapprocher le paiement ».

Si aucune demande n'attend, la fenêtre l'indique. Les codes saisis en caisse et les demandes sur téléphone sans réponse y apparaissent.
