Une personne autre que celle qui a enregistré la demande l'approuve. Une demande que vous avez enregistrée vous-même affiche « Vous avez enregistré cette demande : une autre personne l’approuve. »

Avertissement : « Anonymiser » anonymise les informations de la personne et ne peut pas être annulé. Les ventes, factures et autres documents légaux sont conservés. Vérifiez d'abord l'identité de la personne.

1. Ouvrez Paramètres, puis « Confidentialité ».
2. Dans l'onglet « Demandes sur les données », trouvez une demande « Reçue ».
3. Touchez « Approuver », ou touchez « Rejeter » et rédigez le « Motif », par exemple que l'identité n'a pas été confirmée. Le motif est conservé avec la demande.
4. Pour une demande approuvée, touchez l'action correspondant à son type :
   - « Préparer le rapport » prépare une copie de tout ce qui est détenu sur la personne. Touchez ensuite « Télécharger le rapport ».
   - « Appliquer les rectifications » modifie les informations saisies dans la demande.
   - « Anonymiser » anonymise la personne.
5. La demande passe à « Terminée ».
