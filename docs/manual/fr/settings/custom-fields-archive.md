1. Ouvrez Paramètres, puis « Champs personnalisés ».
2. Choisissez le type d'enregistrement avec les onglets, puis trouvez le champ. Cherchez par libellé ou par clé, ou filtrez par « Type » et « Statut ».
3. Pour le modifier, touchez « Modifier ». La clé et le type sont verrouillés, mais vous pouvez changer le libellé, l'aide, l'ordre, les règles et qui le voit. Touchez « Enregistrer les modifications ».
4. Pour le retirer des formulaires et des listes, touchez « Archiver », puis « Archiver le champ ».

L'archivage conserve les valeurs déjà enregistrées. Restaurer le champ avec « Restaurer » les affiche de nouveau. Touchez « Garder le champ » pour annuler.
