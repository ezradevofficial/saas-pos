Pour les articles, clients, fournisseurs et employés, choisissez si toutes les sociétés de votre groupe utilisent les mêmes enregistrements (« Partagés entre les sociétés ») ou si chacune garde les siens (« Par société »).

Avertissement : cela change qui peut voir quels enregistrements dans toute l'organisation. Le partage rend les enregistrements de chaque société visibles par les personnes de n'importe quelle société, et les codes doivent alors être uniques dans le groupe. Consultez les personnes qui travaillent dans chaque société avant de changer.

1. Ouvrez Données de référence, puis « Partage ».
2. Trouvez le type d'enregistrement et touchez « Modifier ».
3. Lisez les points de la fenêtre. Garder par société signifie que chaque enregistrement appartient à une société ; partager signifie que les enregistrements n'appartiennent plus à une société.
4. Si certains enregistrements n'ont pas encore de société et que vous les gardez par société, choisissez la société qui les reçoit sous « Société qui reçoit les fiches sans société ».
5. Si vous partagez, cochez la case qui confirme que les enregistrements de chaque société deviennent visibles dans le groupe.
6. Touchez « Rendre propres à chaque société » ou « Partager entre les sociétés ».

Si deux sociétés utilisent le même code, le partage est refusé et la page liste les codes à changer d'abord. Touchez « Ne rien changer » pour laisser les choses en l'état.
