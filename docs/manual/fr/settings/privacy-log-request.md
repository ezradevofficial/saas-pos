Une personne peut demander à voir, corriger ou supprimer les données personnelles que vous détenez sur elle. Enregistrez chaque demande ici pour y répondre à temps.

1. Ouvrez Paramètres, puis « Confidentialité ».
2. Dans l'onglet « Demandes sur les données », touchez « Enregistrer une demande ».
3. Sous « La demande concerne un », choisissez « Client », « Employé » ou « Utilisateur », puis choisissez la personne sous « Personne ».
4. Choisissez la « Demande » : « Accès », « Rectification » ou « Effacement ».
5. Pour une correction, remplissez uniquement les informations qui changent sous « Informations rectifiées ».
6. Rédigez une « Note » : comment la demande est arrivée et comment vous avez vérifié l'identité de la personne.
7. Touchez « Enregistrer la demande ».

Chaque demande indique sa date de réception et son échéance. Les demandes en retard sont signalées. Utilisez le filtre « Afficher » pour voir les demandes ouvertes, terminées ou rejetées.
