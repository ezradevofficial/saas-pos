Payez par mobile money ou par carte. Si une facture reste impayée, les caisses cessent d'envoyer les ventes et la vente est suspendue. Les ventes déjà faites restent sur les caisses et sont envoyées dès que vous payez.

1. Ouvrez Paramètres, puis « Abonnement ».
2. Sous « Factures », trouvez la facture. Utilisez « Rechercher par numéro » si la liste est longue.
3. Touchez « Payer » à côté d'elle.
4. Sous « Payer avec », choisissez un numéro mobile money enregistré, un autre numéro, ou « Carte, sur la page du prestataire ».
5. Pour le mobile money, vérifiez le « Numéro de téléphone ».
6. Touchez « Payer » avec le montant.
7. Pour le mobile money, validez la demande sur le téléphone. La page se met à jour toute seule et affiche « Paiement reçu ».
8. Pour une carte, terminez le paiement sur la page du prestataire de carte.

Pour télécharger une facture, touchez « PDF ».

## Enregistrer un moyen de paiement

Sous « Moyens de paiement », touchez « Ajouter un mobile money » ou « Ajouter une carte ». Le moyen par défaut renouvelle votre abonnement automatiquement. Les données de carte restent chez le prestataire. Touchez « Définir par défaut » pour changer le moyen par défaut, ou « Retirer » pour en supprimer un.
