Une succursale est un magasin ou un bureau. Un emplacement est un lieu à l'intérieur où l'on vend ou garde du stock, comme un point de vente, un entrepôt ou un magasin. Les caisses sont associées aux emplacements.

## Ajouter une succursale

1. Ouvrez Paramètres, puis « Organisation ».
2. Sur la société, touchez « Ajouter une succursale ».
3. Saisissez le « Nom ».
4. Saisissez le « Code de succursale » : jusqu'à 20 lettres, chiffres ou tirets, comme WSTL. Il figure sur les tickets et les rapports.
5. Touchez « Ajouter une succursale » dans la fenêtre.

## Ajouter un emplacement

1. Sur la succursale, touchez « Ajouter un emplacement ».
2. Saisissez le « Nom ».
3. Choisissez le « Type d'emplacement » : point de vente, entrepôt, magasin ou bureau.
4. Saisissez le « Code du site » : jusqu'à 10 majuscules ou chiffres, comme L01. Il est imprimé dans les numéros de ticket.
5. Touchez « Ajouter un emplacement » dans la fenêtre.

Un rôle de succursale couvre ses emplacements, et un rôle de société couvre ses succursales. Voir « Donner un rôle à une personne ».
