Votre organisation se compose de sociétés, qui contiennent des succursales, qui contiennent des emplacements. Une seule société suffit pour commencer.

1. Ouvrez Paramètres, puis « Organisation ».
2. Touchez « Ajouter une société ».
3. Saisissez le « Nom ».
4. Saisissez la « Raison sociale » telle qu'enregistrée. Laissez vide pour utiliser le nom.
5. Choisissez le « Pays ». Il détermine la devise et le fuseau horaire. Il ne peut pas être changé ensuite.
6. Saisissez le « Numéro fiscal ».
7. Touchez « Ajouter une société » dans la fenêtre.

Pour modifier une société, touchez « Modifier » à côté d'elle. Pour voir les sociétés archivées, activez « Afficher les éléments archivés ».
