Vous créez le compte une seule fois pour votre entreprise. Vous en devenez le propriétaire. L'essai dure 14 jours et ne demande aucun moyen de paiement.

1. Ouvrez {{app_name}} dans votre navigateur et allez à « Commencez votre essai gratuit ».
2. Choisissez votre « Pays » et votre « Langue », puis touchez « Continuer ». Le pays détermine votre devise, vos taxes et la facturation électronique ; il ne peut pas être changé ensuite.
3. Sur « Créez votre compte », saisissez « Votre nom ».
4. Saisissez votre « Adresse e-mail ».
5. Saisissez un « Nouveau mot de passe ». Il compte au moins 8 caractères. Évitez les mots de passe courants.
6. Saisissez le « Nom de l'entreprise ».
7. Touchez « Créer le compte ».
8. Sur « Saisissez votre code », saisissez le code à 6 chiffres qui vous a été envoyé, puis touchez « Vérifier et continuer ». S'il n'arrive pas, touchez « Envoyer un nouveau code ».

Vous passez ensuite à la prise en main, où vous choisissez votre type d'activité et vos modules.

Pour vous connecter plus tard, utilisez « Se connecter » avec la même adresse e-mail et le même mot de passe. Si vous oubliez le mot de passe, touchez « Mot de passe oublié ? ».
