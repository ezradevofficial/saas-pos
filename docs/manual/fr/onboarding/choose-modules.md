Après la vérification de votre compte, la prise en main prépare la caisse, les rôles et les étapes d'approbation adaptés à votre activité. Vous pourrez tout modifier ensuite.

1. Sur « Quel type d'activité avez-vous ? », choisissez le type le plus proche.
2. Saisissez le nom d'« Entreprise » et choisissez le « Nombre de points de vente ».
3. Touchez « Continuer vers les modules ».
4. Sur « Choisissez vos modules », activez les modules dont vous avez besoin. Les modules habituels pour votre type d'activité sont déjà choisis. Chaque module indique ce qu'il couvre.
5. Réglez le nombre de points de vente, d'appareils de caisse et d'employés avec les boutons moins et plus. Certains nombres changent le prix.
6. Choisissez le « Cycle de facturation » : mensuel ou annuel. L'annuel offre 2 mois.
7. Lisez votre prix à droite. Si une offre groupée couvre vos modules pour moins cher, touchez le bouton qui commence par « Prendre ».
8. Touchez « Commencer l'essai gratuit ».

Vous ne payez rien pendant 14 jours. Les prix sont hors TVA. Vous pourrez ajouter ou retirer des modules plus tard sous Paramètres, Abonnement.
