Les étiquettes portent le numéro de l’immobilisation avec un code-barres, imprimées avec le modèle d’étiquette.

1. Ouvrez « Étiquettes » sous « Immobilisations ».
2. Sous « Choisir les immobilisations », cherchez avec « Rechercher des immobilisations » et cochez chaque immobilisation.
3. Touchez « Imprimer » suivi du nombre d’étiquettes, par exemple « Imprimer 3 étiquettes ». Les étiquettes s’ouvrent prêtes à imprimer.
4. Touchez plutôt « Télécharger le PDF » pour garder un fichier.

Vous pouvez aussi imprimer une étiquette depuis la page de l’immobilisation avec « Imprimer l’étiquette ».
