Un poste est un intitulé de fonction dans une société, comme Caissier. Vous le choisissez à l’embauche ou en rédigeant un contrat.

1. Ouvrez « Postes » sous « Personnel ». S’il y a plusieurs sociétés, choisissez d’abord la société.
2. Cherchez avec « Cherchez par code ou intitulé ». La liste montre le « Code », l’« Intitulé », le « Service », l’« Échelon » et le « Statut ».
3. Touchez « Ajouter un poste ».
4. Saisissez le « Code » et l’« Intitulé ». Choisissez un « Service » si le poste en dépend ; « Aucun service » le laisse ouvert. Ajoutez l’« Échelon » si vous utilisez des échelons.
5. Touchez « Enregistrer les modifications ».

Pour modifier un poste, touchez « Modifier », puis « Enregistrer les modifications ». Pour en retirer un, touchez « Archiver » ; les personnes qui l’occupent le gardent. Touchez « Restaurer » pour le remettre.
