Les types de congé décident de ce que le personnel peut demander et de la façon dont les jours s’accumulent. Les types légaux viennent du pack pays, mais {{app_name}} ne devine jamais combien de jours votre société accorde : vous les saisissez et les confirmez.

1. Ouvrez « Congés » sous « Personnel », puis l’onglet « Types de congé ». Choisissez la société s’il y en a plusieurs.
2. Touchez « Ajouter les types légaux » pour importer les types définis par le pack pays.
3. Un bandeau « Certains types de congé attendent leurs jours » liste les types sans nombre de jours. Sur chacun, touchez « Saisir les jours », saisissez les « Jours par an » (jusqu’à 2 décimales, par exemple 21 ou 1.75), cochez « J’ai vérifié ces jours au regard de la loi et de nos règles » et touchez « Confirmer les jours ». Le personnel ne peut pas demander ce congé avant.
4. Pour ajouter votre propre type, touchez « Ajouter un type de congé ». Saisissez le « Code » et le « Nom », et cochez « Congé payé » s’il est payé.
5. Choisissez l’« Acquisition » : « Non suivi », « Chaque année au 1er janvier » ou « Chaque mois ». Réglez les « Jours par an » et le « Plafond de report » (vide : aucun plafond ; 0 : rien n’est reporté).
6. Choisissez le mode de décompte : « Jours ouvrables » ou « Jours calendaires ». Cochez « Autoriser un solde négatif » ou « Un justificatif est exigé » si cela s’applique.
7. Touchez « Enregistrer les modifications ».

La liste montre pour chaque type la « Rémunération », l’« Acquisition », les « Jours par an », les « Règles » et le « Décompte en ». Touchez « Modifier » pour changer un type, ou « Archiver » pour le retirer : le personnel ne peut plus le demander, et les demandes et soldes passés restent.

Après avoir changé les acquisitions, voir « Suivre les demandes de congé et les soldes » pour lancer l’acquisition.
