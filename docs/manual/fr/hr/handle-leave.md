Les demandes de congé sont décidées dans la boîte des approbations. Les types de congé légaux viennent du pack pays.

1. Ouvrez « Congés » sous « Personnel ». L’onglet « Demandes » liste les « Demandes de congé ».
2. Recherchez par numéro ou par motif. Touchez une demande pour lire le type de congé, les dates, les « Jours » et le « Motif ».
3. Pour décider d’une demande, touchez « Ouvrir les approbations ». Voir « Décider des approbations ».
4. Pour arrêter une demande ou rendre les jours, ouvrez-la et touchez « Annuler le congé », saisissez le « Motif de l’annulation » et confirmez.
5. Ouvrez l’onglet « Soldes » pour voir les jours disponibles par employé et par type de congé, à une date.
6. Si vous pouvez gérer les congés, touchez « Ajuster le solde » pour une personne, ou « Lancer l’acquisition » pour ajouter les jours de la période à tous.
