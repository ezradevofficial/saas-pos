Ouvrez une commande pour une table de la salle, ou une addition pour un client au bar.

1. Ouvrez le menu de la caisse et choisissez « Salle ».
2. Sous « Vue », choisissez « Salle » ou « Additions ». Sous « Afficher », choisissez « Les miennes » pour ne voir que les vôtres, ou « Toutes » pour voir toute la salle.
3. Pour une table, touchez une table libre. Sur « Ouvrir <table> », réglez « Couverts » avec « Plus de couverts » et « Moins de couverts », puis touchez « Ouvrir la table ».
4. Pour une addition, touchez « Nouvelle addition ». Saisissez le « Nom de l’addition », ajoutez un « Client (facultatif) » si vous le souhaitez, puis touchez « Ouvrir l’addition ».

Une table aussi ouverte sur une autre caisse affiche un avertissement : vérifiez avec l'autre serveur avant d'envoyer. Pour une vente sans table, choisissez « Vente rapide » dans le menu de la caisse.
