Chaque ligne est une chambre réservée, pour l'établissement que vous choisissez.

1. Ouvrez « Réservations ». Cherchez par numéro de réservation ou client, et filtrez par statut et dates.
2. Ouvrez une réservation pour lire le séjour, le client, les tarifs « Nuit par nuit » et son folio. Touchez « Ouvrir le folio » pour voir la note.
3. Pour modifier le séjour, touchez « Modifier les dates ou les personnes », changez les dates, les « Adultes » ou les « Enfants », puis touchez « Enregistrer les modifications ». Quand le client est présent, seuls le départ, les personnes et les notes peuvent changer.
4. Pour encaisser de l'argent à l'avance, touchez « Encaisser un acompte ».
5. Pour annuler, touchez « Annuler le séjour ». La page affiche « Les frais seront de » selon la règle d'annulation. Donnez un « Motif » et confirmez. Un responsable peut toucher « Annuler les frais ».
6. Si le client ne s'est pas présenté, touchez « Marquer comme non présenté » et confirmez.

Pour faire une nouvelle réservation, voir « Créer une réservation ».
