Le rapport montre comment chaque fournisseur a livré sur les 90 derniers jours, sauf si vous choisissez d’autres dates.

1. Ouvrez « Performance fournisseurs » sous « Achats ».
2. Réglez « Du » et « Au » pour changer la période. Si vous avez plusieurs sociétés, choisissez la « Société ».
3. Lisez les tuiles : « Fournisseurs », « Bons de commande », « Ponctualité moyenne » et « Qualité moyenne ».
4. Dans le tableau, comparez pour chaque fournisseur les taux « À l’heure » et « Qualité », le « Délai moyen » et l’« Écart de prix ».
5. Touchez « Exporter en CSV » pour reprendre le tableau dans un tableur.

Quand rien n’a été acheté sur la période, la page indique « Aucun achat sur cette période. »
