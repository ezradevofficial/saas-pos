Votre code PIN sert à vous connecter aux caisses. Personne ne peut le lire, pas même un administrateur. Vous le définissez dans le back-office, avec le mot de passe de votre compte.

1. Connectez-vous au back-office sur un ordinateur.
2. Ouvrez Paramètres, puis « Mon code PIN caisse ».
3. Touchez « Définir le code PIN ». Si vous en avez déjà un, le bouton est « Changer le code PIN ».
4. Saisissez le mot de passe de votre compte dans « Mot de passe de votre compte ».
5. Saisissez votre code dans « Nouveau code PIN », puis saisissez-le à nouveau dans « Répétez le code PIN ».
6. Touchez « Enregistrer le code PIN ».

Un code PIN compte 4 à 6 chiffres. Évitez les chiffres répétés, les suites comme 1234 et les codes courants. Si votre rôle peut approuver des annulations, des remboursements ou des changements de prix, votre code PIN doit compter 6 chiffres.

Pour ne plus vous connecter aux caisses, touchez « Supprimer le code PIN ». Vous ne pourrez plus vous connecter à une caisse tant que vous n'en aurez pas défini un nouveau.
