Les notifications sont les messages que l’application vous envoie : une approbation en attente, un bulletin de paie comptabilisé, une livraison en retard. La cloche de la barre du haut indique combien sont non lues.

1. Touchez la cloche pour lire les dernières. Touchez « Tout voir » pour ouvrir la page « Notifications ».
2. Utilisez les onglets « Non lues », « Toutes » et « Archivées ». Saisissez dans la recherche pour trouver un sujet ou un message.
3. Touchez une notification pour ouvrir la page concernée. Elle est marquée comme lue.
4. Pour en marquer une comme lue sans l’ouvrir, touchez « Marquer comme lue » sur sa ligne.
5. Pour ranger ce que vous avez traité, touchez « Archiver ». Les notifications archivées restent dans l’onglet « Archivées ».
6. Touchez « Tout marquer comme lu » pour remettre le compteur à zéro.

Vous choisissez les notifications que vous recevez, et par quel canal, dans vos réglages de notification.
